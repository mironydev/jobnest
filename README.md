# JobNest

[JobNest.com](https://jobnest-x.vercel.app/)

JobNest is a modern job search platform built as a hobby project.

It allows users to search for jobs, explore companies, save opportunities, apply for jobs, and manage their applications.

## Features

- Job search and filtering
- Job details and applications
- Saved jobs
- Company discovery
- Recruiter dashboard
- Job listing management
- Application management
- Admin dashboard
- User authentication
- Pricing and subscriptions
- Responsive design
- Dark mode

## Tech Stack

- Next.js
- React
- JavaScript
- Tailwind CSS
- HeroUI
- Better Auth
- Express.js
- MongoDB
- Nodemailer
- Vercel

## Note

JobNest is a personal hobby project and is not completely finished yet. I plan to continue developing and improving it over time as I learn and experiment with new ideas.
